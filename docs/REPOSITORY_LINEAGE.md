# Repository lineage

This is a standalone reference demonstrator. The links below identify independent repositories that informed the product boundary. They are not imported modules, tested integrations, production dependencies, or evidence of a shared runtime.

| Repository                                                                                                         | Observed scope and contribution                                                                                                                                                                                                                                             | Reuse/adaptation here                                                                                                                             | Limit                                                                                                                                                                               |
| ------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [payflow-control-plane](https://github.com/vishnugovind10/payflow-control-plane)                                   | Local source inspected: typed payment intent, synthetic route fixtures, hard route eligibility checks, FX/provider/liquidity cost calculation, weighted route ranking, concurrent reservations, simulated execution/settlement/reconciliation, FastAPI and React dashboard. | Reimplemented a smaller TypeScript decision model for route fee + FX comparison, deadlines, route availability and shared portfolio reservations. | No code was copied. The demonstrator omits mandate/compliance gates, probabilistic loss, capital cost, API, persistence and actual settlement. Its route assumptions are synthetic. |
| [temporal-liquidity-risk](https://github.com/vishnugovind10/temporal-liquidity-risk)                               | Source inspected: a minimal simulation of synchronized liquidity calls where time concentration can cause failure despite sufficient collateral. It explicitly describes itself as structural, not a realistic market simulator.                                            | Reinforces the need to model deadlines and timing windows alongside aggregate balances.                                                           | No temporal liquidity simulation, collateral reuse model, or code is included here.                                                                                                 |
| [institutional-settlement-state-machine](https://github.com/vishnugovind10/institutional-settlement-state-machine) | Local README and source inventory inspected: deterministic synthetic state machine and scenario catalogue for institutional settlement, invariants, evidence, divergence and reconciliation.                                                                                | Informs the separation between recommendation, execution, settlement and reconciliation.                                                          | Not integrated; payment lifecycle is a UI explanation only.                                                                                                                         |
| [agentic-financial-consequence](https://github.com/vishnugovind10/agentic-financial-consequence)                   | Local README and source inventory inspected: bounded deterministic benchmark comparing authorized intent with observed execution, settlement, liquidity and reconciliation consequences.                                                                                    | Informs the explicit synthetic boundary and no false settled/assured status.                                                                      | Not integrated; this prototype does not observe real outcomes.                                                                                                                      |
| [agent-trust-probe](https://github.com/vishnugovind10/agent-trust-probe)                                           | Local README and source inventory inspected: broader agent authority, consequence, exposure and capacity controls.                                                                                                                                                          | Adjacent authority context; not treated as the core product.                                                                                      | No identity, trust score or authorization service included.                                                                                                                         |
| [agentic-finops-ledger](https://github.com/vishnugovind10/agentic-finops-ledger)                                   | Source inspected: a FinOps gateway with cost governance, simulated financial models, provider evidence, reconciliation, SQLite ledger and dashboard. | [FXRisk](https://github.com/vishnugovind10/FXRisk)                                                                 | Source inspected: a small MetaTrader/MQL4 collection for lot sizing and order-management utilities.                                                                                                                                                                         | No direct route-economics mechanism identified for reuse.                                                                                         | It is not an FX quote, spread or treasury FX-risk engine; nothing is reused.                                                                                                        |

Related repositories are intellectually adjacent only. This repository does not establish shared runtime, imported source, tested integration, deployment, customer adoption, or endorsement.
