# Validation plan

1. Select one corridor with a payment operator and obtain permissioned historical obligations, route quotes, execution outcomes and reconciliation exceptions.
2. Define the incumbent baseline and cost methodology before comparing plans.
3. Run the engine in shadow mode. Record every input, quote timestamp, constraint, recommendation and operator override.
4. Compare all-in cost, on-time settlement, liquidity utilisation, failed/repair payments and reconciliation exceptions. Attribute differences to observed records, not modelled savings.
5. Review data access, product boundaries, implementation ownership, security requirements and budget with the buyer.
6. Continue only if the operator can identify an operational owner and a measurable pilot question.

This prototype is not connected to real systems and has no real-world outcomes.
